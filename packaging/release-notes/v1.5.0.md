The search now edits like a normal text field, with a movable caret, selection, copy, cut, paste and undo. A pasted folder path opens in your file manager with Enter.

![Part of the search selected, with the matching code previewed](https://github.com/crmne/omarchy-files/releases/download/v1.5.0/text-editing.png)

## New

- **Edit the search like any text field.** `←` `→` move the caret, `Shift` selects, `Ctrl ←` `Ctrl →` jump by word, and `Home`, `End`, `Delete`, `Ctrl A` and `Ctrl Z` work. Click to place the caret, drag to select, double click to select everything. The arrows still navigate at the ends of the text: `→` at the end browses into a folder, `←` at the start goes back. By @crmne.
- **Copy and cut what you typed.** `Ctrl C` and `Ctrl X` copy and cut selected text. With nothing selected, `Ctrl C` still copies the selected file's path. Clipboard reads still happen only when you paste. By @crmne.
- **Open a pasted folder with Enter.** A folder path ending in `/` lists the folder itself first, previewing its contents, so Enter opens it. A name typed in full ranks first. Pasted paths lose their trailing line break, and a pasted `file://` link becomes its path. By @crmne.

![A pasted folder path lists the folder first, with its contents previewed](https://github.com/crmne/omarchy-files/releases/download/v1.5.0/open-folder.png)

## Fixed

- **Open folders in your default file manager.** Enter on a folder now uses your default application for folders instead of always starting Nautilus. Show in Files still uses Nautilus to select the item. By @crmne.
- **Read file sizes at a glance.** The preview shows sizes such as 318.6 MB instead of a raw byte count in scientific notation. By @crmne; thanks @crmne for the report.
- **Climb a typed path with Ctrl Backspace.** `←` now moves the caret, so climbing one folder in a typed path is `Ctrl Backspace` alone. By @crmne.

## Known limitations

- A folder listed first in its own path shows a `→` chevron that keeps you in the same folder.
- Restart the shell with `omarchy restart shell` after updating to clear cached QML.
