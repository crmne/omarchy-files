Files now previews code, PDF pages, images, documents, archives and media beside your search results. Code uses Neovim's configured theme and the same system font as the overlay.

![Code preview in the configured Neovim theme](https://github.com/crmne/omarchy-files/releases/download/v1.3.0/preview-code.png)

## New

- **Read code in your Neovim colors.** Syntax highlighting uses Neovim's bundled syntax definitions and the configured Omarchy Neovim theme, including its options and background. The system font is preserved. By @crmne.
- **Browse PDF pages and more image formats.** Previous and next controls turn PDF pages. Image previews include SVG, TIFF, AVIF, ICO, PSD and other supported formats. By @crmne.
- **Preview documents and archives.** Read text from modern Office documents, OpenDocument files and EPUB, or list archive contents without extracting them. By @crmne.
- **Listen to audio and inspect video frames.** Choose a position and explicitly play up to 30 seconds of audio. Video previews show seekable frames; Enter opens the full video in its associated app. Playback stops when selection changes or Files closes. By @crmne.
- **Keep navigation responsive.** Bounded decoding runs outside the shell, selection changes cancel stale work, and an in-memory cache reuses unchanged previews. By @crmne.

## Known limitations

- Optional decoders are not installed automatically: Neovim for highlighting, Pillow for raster images, Poppler for PDFs, FFmpeg for media, librsvg for SVG and libarchive for archive listings.
- Code and text previews show at most 16 KiB. Large, encrypted and unsupported files fall back to file information or an unavailable message. Older binary Office formats are not supported.
- Neovim colors follow `~/.config/nvim/lua/plugins/theme.lua` and its already installed theme package. Unsaved colorscheme changes inside an existing editor session are not reflected. General editor configuration, plugin-manager startup and file modelines are disabled.
- Video previews show frames, not continuous video playback. Audio previews are limited to 30 seconds and never autoplay. Audio tests used a silent output driver.
- Symbolic links and special files do not get content previews. The preview pane hides below 900 logical pixels of screen width.
- Restart the shell with `omarchy restart shell` after updating to clear cached QML.
