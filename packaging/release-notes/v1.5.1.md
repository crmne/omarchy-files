Files 1.5.1 makes moving a file to the Trash take a deliberate key press, and keeps spreadsheet previews small.

## Fixed

- **A held Enter no longer confirms the Trash.** Enter on the Trash action opens the confirmation with Trash selected, so holding the key down could move the file to the Trash through key repeat. The confirmation now ignores repeated Enter, and only a fresh press confirms. By @crmne, from the marketplace security review.
- **Spreadsheet previews stay within their limit.** A small `.xlsx` whose cells all repeat one long piece of text could expand to far more than the preview shows, and run the preview helper out of memory, so nothing was previewed. The preview now stops reading cells once it has enough text. By @crmne, from the marketplace security review.

## Known limitations

- A folder listed first in its own path shows a `→` chevron that keeps you in the same folder.
- Restart the shell with `omarchy restart shell` after updating to clear cached QML.
