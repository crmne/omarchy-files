Type or paste a path to go anywhere on your system. Files now browses and previews paths outside your home folder, one keystroke at a time.

![A typed path selecting /etc/os-release and previewing it](https://github.com/crmne/omarchy-files/releases/download/v1.4.0/browse-path.png)

## New

- **Paste a path to preview it.** A search starting with `/` or `~/` lists that folder, narrowed by the name you are typing, so a full path such as `/etc/hosts` selects the file and shows its preview, even outside the search folder. By @crmne.
- **Browse from the top of the file system.** Type `/` to list it, `→` on a folder to add it to the path, and `←` or `Ctrl Backspace` to climb one folder at a time. Symbolic links such as `/bin` can be followed, gitignored files are listed, and hidden entries appear once the name you type starts with a dot. By @crmne.

![Typing /us narrows the top of the file system to /usr and lists its contents](https://github.com/crmne/omarchy-files/releases/download/v1.4.0/browse-folder.png)

## Known limitations

- Search results are still previewed only inside the search folder. Paths outside it are previewed only when you type or paste them.
- Symbolic links themselves show file information instead of a preview; `→` still follows a linked folder.
- With nothing typed after the last `/`, a folder lists its first 500 entries. Typing part of a name searches all of them.
- Restart the shell with `omarchy restart shell` after updating to clear cached QML.
