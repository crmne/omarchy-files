Files now has settings inside the overlay and a preview beside the selected file, using Omarchy's menu font throughout.

![Image preview beside the selected file](https://github.com/crmne/omarchy-files/releases/download/v1.2.0/image-dark.png)

## New

- **Configure Files without leaving the overlay.** Click the settings icon to flip to search location, exclusions, opening shortcut, preview visibility, and index rebuilding. Back returns to your search. By @crmne.
- **Apply an opening shortcut from settings.** Explicitly enable Apply shortcut to Hyprland before saving. Files checks for conflicts, writes a dedicated shortcut file, keeps backups, and restores the previous files if validation fails. By @crmne.
- **Preview the selected file on the right.** Read bounded plain text, see image thumbnails, or inspect basic file information. Image decoding runs in a separate process with input, memory, pixel, and time limits; previews are kept in memory. By @crmne.

![Settings inside Files](https://github.com/crmne/omarchy-files/releases/download/v1.2.0/settings-dark.png)

## Fixed

- **Settings belong inside the overlay.** Removed the bar widget introduced in 1.1.0. Remove its Files entry from bar settings if you added it. By @crmne; thanks @crmne for clarifying the intended placement.
- **Use the same Omarchy font throughout.** Settings labels, fields, buttons, and file previews inherit the overlay's menu font. By @crmne; thanks @crmne for reporting the mismatch.
- **Keep indexed paths private.** Cache directories and newly written index files are restricted to your user. Exclusion changes get their own index and also apply when browsing folders. By @crmne.

## Known limitations

- System Python and `python-pillow` are required for image thumbnails.
- Text previews show at most 16 KiB. Raster image previews accept files up to 8 MiB and 16 million pixels. PDFs and unsupported formats show file information.
- Symbolic links and special files do not get content previews. The preview pane hides below 900 logical pixels of screen width.
- Shortcut setup requires Omarchy's Lua configuration at `~/.config/hypr/bindings.lua`. Supported keys are Space, letters, digits, and F1 through F12 with modifiers.
- Restart the shell with `omarchy restart shell` after updating to clear cached QML.
