Files now has a bar button, a visible typing cursor, and clipboard paste support.

![Files search with its typing cursor](https://github.com/crmne/omarchy-files/releases/download/v1.1.0/search.png)

## New

- **Open Files with a click.** Add Files in the bar settings to open search without a keyboard shortcut. By @crmne.
- **Paste into searches and action filters.** Ctrl+V and Shift+Insert read the clipboard only on request, with size and time limits. Delayed results are discarded if you edit, navigate, or close Files. By @crmne.
- **Set up a familiar shortcut.** The marketplace description and README now explain how to configure Ctrl+Alt+Super+Space in Hyprland. By @crmne.

## Fixed

- **See where you can type.** A blinking caret appears in the search header, including when the search is empty. By @crmne.
- **Keep theme colors working with the installed Qt version.** Files now explicitly resolves Omarchy's color module. By @crmne.

## Known limitations

- Keyboard shortcuts require manual setup. Installing Files does not change your Hyprland bindings.
- Restart the shell with `omarchy restart shell` after updating an already loaded copy. A plugin rescan can retain cached QML.
- Pasted text is limited to 4096 bytes per request; line breaks become spaces.
